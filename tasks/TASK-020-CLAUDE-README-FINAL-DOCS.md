## Objective

Replace the development-heavy README/documentation with concise, realistic student-project documentation.

## README requirements

Write a new `README.md` that includes only useful final information:

1. Project name and short idea.
2. Problem/purpose.
3. Main features.
4. Roles:
   - User/Buyer;
   - Merchant;
   - Admin.
5. Technology stack.
6. High-level architecture.
7. Database:
   - SQL Server;
   - EF Core;
   - Code First;
   - migrations;
   - ERD location if retained.
8. Prerequisites.
9. Exact local setup steps.
10. Migration/database setup commands.
11. Demo-data setup instructions.
12. How to run the application.
13. Main demo accounts/emails, without committing a real/shared password.
14. Concise project structure.
15. Known scope limitations only if they are relevant.

## Style

- Student-written and professional.
- Do not use audit language.
- Do not exaggerate.
- Do not claim production readiness.
- Do not mention removed tests, Claude, Codex, agents, skills, task files, or internal project-development machinery.
- Do not include stale test counts.

## Documentation cleanup

Keep only documentation that adds clear submission value. Prefer a small number of concise files over a large development-history archive.

Ensure no retained doc links to a deleted file.
