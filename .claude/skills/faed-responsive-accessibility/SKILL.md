# Faed Responsive and Accessibility Review

## Goal

No UI task is complete until it works well on:
- mobile;
- tablet;
- desktop;
and meets a practical accessibility baseline.

## Responsive checklist

Check:
1. no horizontal overflow;
2. readable spacing at small widths;
3. filters usable on mobile;
4. buttons large enough to tap;
5. forms usable on phone;
6. product cards stack cleanly;
7. tables degrade gracefully;
8. sticky actions do not cover content;
9. image galleries remain usable;
10. CTA remains clear on mobile.

## Accessibility checklist

Check:
1. semantic headings;
2. form labels;
3. field-level errors;
4. keyboard focus visibility;
5. keyboard operability;
6. color contrast;
7. no color-only meaning;
8. alt text strategy;
9. accessible disabled states;
10. status messages understandable;
11. link/button distinction clear.

## Commerce-specific accessibility

Also ensure:
- condition text is understandable;
- discount reason is not icon-only;
- stock state is not color-only;
- selected variant state is visible beyond color;
- error messages explain what the user should do next.

## Output expectation

Before marking a UI task complete, summarize:
- responsive issues found/fixed;
- accessibility issues found/fixed;
- remaining acceptable limitations if any.
